# General

## Repository language is always English
Prompts and chat may be in Dutch; everything committed to the repo is English. That covers identifiers, comments/PHPDoc, commit messages, branch names, test names, docs and user-facing copy (`APP_LOCALE` is `en`). Never mix languages in one file and never translate existing English identifiers. See the "Language (hard rule)" section in AGENTS.md.
